## Шифр Цезаря

Приложение для шифрования и дешифрования текста с использованием алгоритма шифрования Цезаря, разработанное на языке C# с графическим интерфейсом Windows Forms.


## Цель проекта

Разработать приложение с графическим интерфейсом для шифрования и дешифрования текстовой информации с использованием алгоритма Цезаря, возможностью настройки ключа шифрования и сохранения результатов в текстовые файлы.

## Описание проекта

Шифр Цезаря — программа, предназначенная для шифрования и дешифрования текстовой информации с помощью сдвига символов алфавита на заданное количество позиций.

Приложение позволяет пользователю вводить текст, выбирать ключ шифрования, получать зашифрованный результат, а также расшифровывать текст из файлов.

## Возможности

- Шифрование текста с использованием алгоритма Цезаря.
- Выбор величины сдвига от 2 до 32 позиций.
- Отображение зашифрованного текста.
- Сохранение зашифрованного текста в файл формата `.txt`.
- Загрузка зашифрованного текста из файла.
- Дешифрование текста с использованием ключа сдвига.
- Отображение расшифрованного текста.
- Сохранение расшифрованного текста в файл формата `.txt`.
- Графический интерфейс Windows Forms.

## Используемые технологии

- **Язык программирования:** C#
- **Платформа:** .NET
- **Графический интерфейс:** Windows Forms
- **Среда разработки:** Visual Studio
- **Алгоритм шифрования:** Шифр Цезаря

## Принцип работы

Программа использует алгоритм шифрования Цезаря, при котором каждая буква исходного текста заменяется другой буквой, расположенной на определённое количество позиций дальше по алфавиту.

Величина сдвига выступает ключом шифрования.

### Шифрование

1. Пользователь запускает приложение.
2. Вводит текст для шифрования.
3. Выбирает величину сдвига от 2 до 32.
4. Нажимает кнопку «Шифровать».
5. Программа выполняет шифрование введённого текста.
6. Зашифрованный текст отображается в интерфейсе.
7. Результат сохраняется в файл формата `.txt`.

### Дешифрование

1. Пользователь выбирает текстовый файл через диалоговое окно.
2. Нажимает кнопку «Дешифровать».
3. Программа выполняет обратное преобразование текста.
4. Расшифрованный текст отображается в интерфейсе.
5. Результат сохраняется в файл формата `.txt`.
